## Вариант А — Всё через Docker (рекомендуется)

Этот способ поднимает PostgreSQL, бэкенд API и runner одной командой.

### Шаг 1 — Запустить Docker Desktop

Открой Docker Desktop и дождись пока он полностью загрузится (иконка в трее станет зелёной).

### Шаг 2 — Запустить бэкенд + БД + runner

```bash
cd ~/Downloads/stackr-java

docker-compose up --build
```

Первый запуск займёт 3–5 минут (скачивает образы, собирает JAR).
Следующие запуски — ~30 секунд.

**Что должно появиться в логах:**
```
postgres   | database system is ready to accept connections
api        | Started StackrApplication in 8.3 seconds
runner     | Started RunnerApplication in 3.1 seconds
```

API будет доступно на **http://localhost:8080**

### Шаг 3 — Запустить фронтенд

Открой **новый терминал** (Docker Compose оставь работать в первом):

```bash
cd ~/Downloads/stackr-java/web

npm install       # только первый раз, потом пропустить

npm run dev
```

Фронтенд будет доступен на **http://localhost:5173**

### Шаг 4 — Открыть приложение

Открой браузер: **http://localhost:5173**

Зарегистрируйся → войди → пользуйся.

## Остановка

```bash
# Остановить Docker (в первом терминале)
Ctrl+C

# Или полностью удалить контейнеры
docker-compose down

# Удалить вместе с данными БД (сбросить всё)
docker-compose down -v
```

## Вариант Б — Вручную (для разработки в IntelliJ)

Используй этот вариант если хочешь редактировать код и сразу видеть изменения.

### Шаг 1 — Запустить только PostgreSQL через Docker

```bash
cd ~/Downloads/stackr-java

docker-compose up postgres
```

БД запустится на порту **5432**.

### Шаг 2 — Запустить бэкенд API

Открой **новый терминал**:

```bash
cd ~/Downloads/stackr-java

mvn spring-boot:run
```

Или в IntelliJ: открой `StackrApplication.java` → нажми ▶ Run.

API стартует на **http://localhost:8080**
Liquibase автоматически создаст все таблицы при первом запуске.

### Шаг 3 — Запустить runner

Открой **ещё один терминал**:

```bash
cd ~/Downloads/stackr-java/runner

mvn spring-boot:run
```

Runner стартует на **http://localhost:8081**

### Шаг 4 — Запустить фронтенд

Открой **ещё один терминал**:

```bash
cd ~/Downloads/stackr-java/web

npm install   # только первый раз

npm run dev
```

Открой **http://localhost:5173**

## Запуск тестов

```bash
cd ~/Downloads/stackr-java

# Все тесты (unit + интеграционные)
mvn test

# Только unit-тесты сервисов
mvn test -Dtest="AuthServiceTest,ProblemServiceTest,SubmissionServiceTest,ContestServiceTest"

# Только интеграционные тесты
mvn test -Dtest="*IntegrationTest"
```

Тесты используют H2 in-memory БД — PostgreSQL и Docker не нужны.

## Проверка что всё работает

После запуска можно быстро проверить API через браузер или curl:

```bash
# Проверить что API живой
curl http://localhost:8080/api/tags

# Зарегистрировать пользователя
curl -X POST http://localhost:8080/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","email":"admin@test.com","password":"password123"}'

# Войти и получить токен
curl -X POST http://localhost:8080/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"password123"}'
```

## Частые проблемы

**Порт 5432 занят**
```bash
# Найти и убить процесс
lsof -i :5432
kill -9 <PID>
```

**Порт 8080 занят**
```bash
lsof -i :8080
kill -9 <PID>
```

**`npm install` завершился с ошибкой**
```bash
cd ~/Downloads/stackr-java/web
rm -rf node_modules package-lock.json
npm install
```

**API не подключается к БД**
Убедись что PostgreSQL запущен (`docker-compose up postgres`) и в `application.yml` правильные данные:
- url: `jdbc:postgresql://localhost:5432/stackr_db`
- username: `postgres`
- password: `secret`

**Docker: `permission denied` на `/var/run/docker.sock`**
```bash
sudo chmod 666 /var/run/docker.sock
```
