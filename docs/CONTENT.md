# Демонстрационное наполнение Stackr

Каталог содержит 20 оригинальных русскоязычных условий классических алгоритмических задач. Тексты не скопированы с LeetCode. Исходные данные: `scripts/content/problems.py`, публикуемые условия и тесты: `scripts/content/catalog.json`.

У каждой задачи есть формат ввода и вывода, ограничения, Java-шаблон, два открытых примера и скрытые проверки. Всего 345 тест-кейсов. Java-решения сверены с независимыми Python-вычислениями; затем каждое из 20 решений отправлено через HTTP в настоящий Docker judge и получило AC. Это не исчерпывающая проверка всех возможных входов или сложности любого пользовательского решения.

Темы: массивы, хеш-таблицы, стек, два указателя, префиксные суммы, жадные алгоритмы, динамическое программирование и сортировки.

## Тренировка

«Алгоритмический старт» содержит пять задач: «Одна сделка на бирже», «Перенос нулей», «Следующий больший элемент», «Возрастающая подпоследовательность», «Вода между стенами».

Это бессрочная локальная тренировка. Технически используется дата окончания 9999-12-31; интерфейс распознаёт её как бессрочную и скрывает таймер/дату окончания. Таблица использует общие правила решённых задач и штрафа. Это не отдельный сезонный рейтинг.

## Видимость контестов

- Общий каталог: только публичные, ещё не завершившиеся контесты.
- «Мои контесты» организатора: его публичные и приватные незавершённые контесты.
- Приватный контест не появляется в публичном каталоге даже после вступления. Участник открывает его по приглашению, а после вступления — также по прямому адресу.
- Знание числового ID не открывает чужой приватный контест. Ссылку может передать любой её обладатель; это приглашение по ссылке, а не персональное приглашение по email.
- Замена ссылки прекращает работу старого приглашения, но сохраняет доступ вступивших. Завершённые контесты доступны по ранее разрешённым прямым ссылкам и истории, но не рекламируются в каталоге. Свою задачу без посылок можно удалить из собственного завершённого контеста без посылок: связь снимается автоматически. Состав контестов с историей сохраняется.

## Обслуживание локальных данных

Перед первоначальным изменением данных сохранён проверенный PostgreSQL dump в игнорируемой папке backups. Чужие аккаунты и история посылок не удалялись. QA/smoke-ресурсы скрываются и архивируются; сгенерированные аккаунты отключаются. Проверочная задача «111» скрыта с сохранением истории.

Команды из корня проекта:

```sh
python3 scripts/content/build_catalog.py  # javac/java нужны для доверенных эталонов
python3 scripts/seed-demo.py             # импорт/обновление 20 задач и тренировки
python3 scripts/verify-demo.py           # все эталоны через реальный judge
bash scripts/e2e.sh                     # браузерная приёмка, затем уборка QA
python3 scripts/cleanup-qa.py            # уборка после отдельных проверок
python3 scripts/capture-demo.py          # чистые скриншоты локального сайта
```

`.demo-content.json` хранит пароль только сгенерированной редакционной учётной записи, имеет права 600 и исключён из Git/Docker. Импорт временно даёт ADMIN только этой новой учётной записи для создания тем и возвращает ORGANIZER в finally. Существующие администраторы не изменяются.

Браузерный прогон по умолчанию очищает свои данные даже при падении сценария; `STACKR_KEEP_QA=1` оставляет их для диагностики. Не запускайте очистку одновременно с другими проверками, использующими QA-аккаунты. Блокировочный файл `.demo-validation.lock` позволяет временно отложить очистку при совместной диагностике.

Роудмап посвящён алгоритмам и структурам данных. Ознакомились с описанием https://itbooster.ru/roadmap/20/; динамическую внутреннюю схему просмотрщик не загрузил, поэтому карта Stackr не является точной копией этого ресурса. Основы Java и математика исключены по запросу пользователя; учебные материалы по узлам ещё не опубликованы.
